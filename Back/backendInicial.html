Backend

O que ele é?

O backend se trata da parte não visual de um software, ele trata tudo sobre a lógica de funcionalidade e regras do servidor(exemplo, verificar dados e etc), integrar com bancos de dados e e outros serviços

Para que ele é usado?

É por meio dele que é garantida a segurança de processos, dados e etc dentro de um software

Backend x Frontend

O front se trata da parte visual do programa, pode se diferenciar de acordo com o dispositivo de acesso ao sistema. Porém o back se trata daquilo que faz o sistema rodar indiferente de onde o sistema é acessado(mantém o padrão de funcionamento)

Por que validar no backend?

Porque o front não tem conexão direta com o banco de dados, ele é somente a parte visual do software. Além disso, se a validação (de uma senha, por exemplo) ficar só no front, qualquer um pode alterá-la pelo DevTools, já que o front roda no computador do usuário. O back roda no servidor, que o usuário não controla, por isso as regras de verdade ficam lá.
