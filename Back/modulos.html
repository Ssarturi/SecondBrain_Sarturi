Módulos e require()

O que é um módulo?

Um arquivo JavaScript que eu uso dentro de outro arquivo. Cada arquivo .js é um módulo.

Por que existe?

Para dividir um código gigante em partes pequenas, por assunto, fáceis de achar. Assim, mexer em uma parte também não quebra as outras.

Os 3 tipos de módulo no Node

Tipo Exemplo
Meus próprios arquivos Arquivos que eu crio
Já vêm no Node os, fs (lê arquivos do PC)
Pacotes do NPM (dependências) cowsay, dayjs

Toda dependência é um módulo, mas nem todo módulo é uma dependência (dependência é o que vem de fora, pelo NPM, e fica listado no package.json).

O que é o require()?

Uma função que pega um módulo e entrega para eu usar no arquivo. Instalar um pacote só baixa ele; para usar no código, preciso do require(). O texto entre aspas é o nome do módulo.

Exemplo: módulo que já vem no Node

const os = require("os");

console.log("Sistema:", os.platform());
console.log("Memória livre:", os.freemem());

require("os") guarda o módulo na constante os; depois uso as funções que ele oferece, como os.platform().

Exemplo: pacote do NPM

const dayjs = require("dayjs");

console.log("Hoje é", dayjs().format("DD/MM/YYYY"));

O dayjs sozinho é uma função: dayjs() cria a data de agora (sem passar nada) e é essa data que tem o .format(). O texto dentro do format é o modelo da data (DD = dia, MM = mês, YYYY = ano).

Lembrete

O require() só traz o módulo. O que cada módulo oferece, descubro lendo a documentação dele (todo pacote do NPM tem uma).
