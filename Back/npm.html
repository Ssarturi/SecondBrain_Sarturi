NPM

O que ele é?

NPM (Node Package Manager) é o gerenciador de pacotes que vem junto com o Node. Um pacote é um código pronto, escrito por outra pessoa, que eu baixo e uso no meu projeto. É como uma loja de aplicativos, só que de pedaços de código (os pacotes ficam no site npmjs.com).

Por que ele existe?

Para não precisar escrever tudo do zero. Muita gente já resolveu problemas comuns (datas, servidores, senhas...) e publicou o código. O NPM baixa esses pacotes com um comando, sem copiar e colar nada.

Comandos

npm -v               // mostra a versão do NPM
npm install cowsay   // baixa o pacote cowsay para o projeto
npm install          // lê o package.json e baixa tudo que o projeto precisa
npx cowsay "Oi"      // executa um pacote (em vez de instalar)

Os arquivos que aparecem

Pensando numa receita de bolo:

Arquivo O que é Enviar junto com o projeto?
node_modules/ Os ingredientes: o código dos pacotes baixados Não (é pesado e pode ser baixado de novo)
package.json A lista de compras: o que o projeto precisa Sim
package-lock.json A nota fiscal: a versão exata de cada pacote Sim

Por que vieram tantos pacotes?

Pedi só o cowsay, mas vieram uns 30. É porque quem criou o cowsay também usou pacotes de outras pessoas para construí-lo. O NPM baixa tudo o que ele precisa (e o que esses pacotes precisam), numa corrente. Esses pacotes necessários se chamam dependências.

Apagou a node_modules?

Sem problema: rodando npm install, o NPM lê o package.json e o package-lock.json e recria a pasta inteira com tudo que precisa para rodar.
