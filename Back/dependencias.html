Dependências

O que são?

Dependência é qualquer pacote que o meu projeto precisa para funcionar. Exemplo: o cowsay era dependência do meu projeto, e o yargs era dependência do cowsay.

Por que esse conceito existe?

O projeto depende de código que não é meu. Se esse código sumir, o projeto quebra. Por isso o NPM anota tudo no package.json.

Os dois tipos

Tipo Para que serve Exemplo
dependencies O projeto precisa delas para rodar dayjs (formata datas), pacote de matemática
devDependencies Só são usadas enquanto eu programo nodemon (reinicia o programa ao salvar), ferramenta de testes

Regra para decidir: se eu publicar o programa sem esse pacote, ele ainda funciona para quem usar? Se funciona, é devDependency.

Comandos

npm install dayjs                // vai para "dependencies"
npm install nodemon --save-dev   // vai para "devDependencies" (--save-dev = só para desenvolvimento)
npm uninstall dayjs              // remove a pasta da node_modules e a linha do package.json

Como fica no package.json

"dependencies": {
  "dayjs": "^1.11.23"
},
"devDependencies": {
  "nodemon": "^3.1.14"
}
