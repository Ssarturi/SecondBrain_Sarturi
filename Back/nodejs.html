Node.js

O que ele é?

O Node.js é um programa instalado no computador que permite rodar JavaScript fora do navegador: no terminal, em um servidor, onde eu quiser.

Por que ele existe?

Antes, o JavaScript só rodava no navegador, e para o backend era preciso aprender outra linguagem. Com o Node, uso a mesma linguagem no front e no back. E como ele roda fora do navegador, pode fazer o trabalho do backend: ler arquivos do computador, conversar com bancos de dados e criar servidores.

Navegador x Node

Rodando pelo Node, o JS não fica limitado ao navegador: pode acessar arquivos do PC e conversar com bancos de dados (que são outros programas rodando). Em troca, no Node não existe página, então não existem coisas do navegador como o document e o alert().

Como rodar um arquivo

No terminal, dentro da pasta do arquivo:

node -v        // mostra a versão instalada (confirma que o Node funciona)
node ola.js    // executa o arquivo ola.js

Exemplo

const nome = "Sarturi";
console.log(`Olá, ${nome}!`);

const n1 = 4;
const n2 = 6;
const soma = n1 + n2;
const multiplicacao = n1 * n2;

console.log(soma, multiplicacao); // 10 24

Lembretes

Toda variável nasce declarada: const quando o valor não muda, let quando vai mudar. Sem declarar, o JS cria uma variável global escondida, o que gera bugs (e dá erro em modo estrito). Template string: crases com ${variavel} para juntar texto e variável.
